# TaleMod iOS

Theos tweak for Nulls Brawl on iOS 27 / LiveContainer.

## Install

1. Download TaleMod artifact from Actions.
2. Unpack TaleMod.dylib.
3. Copy to Documents/Tweaks/ inside LiveContainer.
4. Remove Titanox.dylib from the same folder.
5. Launch NB via LiveContainer.
6. Enable JIT for NB process via StikDebug.
7. Log: Documents/talemod.log in NB data container.
